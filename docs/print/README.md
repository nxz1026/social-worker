## 给印厂的一段话

> 三个文件都是含 3 mm 出血的 PDF，文字已转曲，按成品尺寸裁切。A5 回访卡和 A6 食安卡用 300 g 白卡、双面四色、不覆膜；KT 板 120 × 90 cm，5 mm KT 板（户外改 PVC），写真贴板或 UV 直喷，1–2 块。请先打样 1 张回访卡、1 张食安卡，确认颜色、裁切和写字手感；KT 板先打小样确认深绿色不偏色。

## 分件说明

- **回访卡**：三版颜色不同（商户橙、居民绿、志愿者蓝），但都是同一套版式。印厂按页序 1–2 商户、3–4 居民、5–6 志愿者，正背对应，不要混版。
- **KT 板**：文件是 1:1（1206 × 906 mm）。如果印厂要求 1:10，按 10 倍放大；四周各留 3 cm 安全边距，落款不要贴边。
- **食安卡**：正面题目、背面答案，正背套准；如果做覆膜题库，配油性笔或白板笔，不要用普通圆珠笔。

## 取件前检查

1. 回访卡：三版各抽 1 张，正背是否对应、裁切有没有切到字、勾选框是否好写。
2. KT 板：深绿底有没有偏色、白字有没有糊、四角有没有翘边；户外用板是否做了防水。
3. 食安卡：6 道题和答案是否对得上、正背有没有倒置、裁切后字号是否还清楚。
